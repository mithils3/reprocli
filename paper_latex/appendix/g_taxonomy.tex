\section{Failure-Mode Taxonomy}
\label{app:taxonomy}

\subsection{Labeling procedure}

% src: .claude/skills/analyze-sweep/SKILL.md:11-24,34-87,113
We assign a run's primary failure mode in a transcript dissection that runs
after the audit and separately from it. The dissection reads the run's ordered
event transcript, the final report the agent emitted, and the audit verdict,
rationale, and flags recorded on the run row, and it assigns exactly one
primary mode per run. The modes are not mutually exclusive as mechanisms, so
the label records the dominant one. A dissection never edits audit scores,
verdicts, or flags, and a mode label therefore never moves a grade. No
dissection carries an availability-wall label. Every artifact in the frozen
benchmark is retrievable by host probe, and where a report asserts otherwise
we relabel the run from its own evidence. We add a new mode to the taxonomy
only on evidence from at least two runs.
Before pooling, we remap sweep-local labels onto the nine modes. Twenty-nine
runs whose dissection carried a label outside the vocabulary, or a label that
disagreed with the pinned verdict, were re-read against the definitions below
and assigned by the agent's recorded behavior. The labels folded this way are
under-determined-target, scope-collapse, unavailability-concluded-from-prose,
context-or-round-exhaustion, fabrication-or-provenance-break,
report-serialization-fault, tool-call-format-collapse,
protocol-drift-direction-flip, eval-protocol-shopping, and
verified-non-attempt. Table~\ref{tab:failure-modes} and
Table~\ref{tab:failure-modes-by-agent} print each mode under a plain-language
name in the order of Table~\ref{tab:taxonomy}.

\subsection{The failure modes}

% src: .claude/skills/analyze-sweep/SKILL.md:74-79; notes/Analysis/2026-07-20 Easy Sweep 2652648 (MiniMax repair).md:118; notes/Analysis/2026-08-04 Easy Sweep 2859889 (Laguna INT4, pinned Sonnet).md:155-166,231-240
The taxonomy has nine modes with fixed names (Table~\ref{tab:taxonomy}). Before
we count anything in a table that pools sweeps, we remap retired names,
underscore spellings, and sweep-local labels onto the nine mode names, and the
caption of that table says so. The band column records where the rubric text
says a mode tends to score. The auditor grades from the run's evidence, has no
access to the mode label, and does not apply the band column as a rule.

\texttt{reproduced-\allowbreak clean} &
The agent runs the authors' released artifact on the authors' data and the
graded quantity falls inside the pinned bar. &
A value computed in the run and traced to a command the transcript contains,
with the released code, checkpoint, and data as inputs. &
8--10 \\
\addlinespace
\texttt{near-\allowbreak miss-\allowbreak partial} &
The agent executes a faithful pipeline and produces a measured number short of
the bar. &
A completed execution of the pinned quantity with sound provenance, and a
measured value on the wrong side of the bar. &
6--7 \\
\addlinespace
\texttt{reimplement-\allowbreak without-\allowbreak validating} &
The agent writes its own version of the method or a component of it and
anchors no stage of it to a reference it did not produce itself. &
A from-scratch component in the run's own code, alongside a reference row the
paper supplies, most often its own baseline in the table that carries the
target, that the transcript never checks against. &
4 \\
\addlinespace
\texttt{environment-\allowbreak fights} &
The decisive rounds go to build and dependency failures in the released stack
on the host machine, and the claim's experiment never reaches a valid number. &
Repeated install, compile, and ABI failures against the authors' pins, with
the same package families recurring across runs on the same host. &
-- \\
\addlinespace
\texttt{artifact-\allowbreak provenance-\allowbreak mismatch} &
The agent measures a checkpoint, dataset, split, or scale other than the one
the dataset row names. &
A retrieved artifact whose own model card, README, or shipped example
disagrees with the dataset row, carrying a measurement taken on it. The
\texttt{wrong\_\allowbreak split\_\allowbreak scale\_\allowbreak dataset} flag names the same break. &
-- \\
\addlinespace
\texttt{scope-\allowbreak substitution} &
The experiment that ran differs from the experiment the pinned claim is
about. &
A round where the agent names the pinned arm and chooses a different one, and
a graded number produced from the substitute. &
0 or 2 \\
\addlinespace
\texttt{stale-\allowbreak artifact-\allowbreak reliance} &
The agent runs the right thing, gets a number that misses, finds a shipped
constant in the repository that passes, and reports the constant. &
The run's own executed value and the reported value differ, and the reported
value traces to a file the repository shipped. The \texttt{stale\_artifact}
flag names the same break. &
4 or 0 \\
\addlinespace
\texttt{procrastination/\allowbreak wall-\allowbreak kill} &
The agent spends its rounds on reading, retrieval, and probing, the pinned
pipeline never runs, and the run stops or is cut off with most of the band
unspent. &
Rounds dominated by search and setup, an own estimate that the pinned run
fits the band, and an exit with the allocation largely unspent. &
-- \\
\addlinespace
\texttt{killed-\allowbreak before-\allowbreak the-\allowbreak number} &
The run produces no measurement of the pinned quantity. The environment and
the artifacts work, and the run ends before the graded command yields a
value. &
A retrieved artifact set and a pipeline the transcript shows running, with no
value for the pinned metric anywhere in the run bundle. &
3 \\
\end{longtable}

\subsection{Failure taxonomy examples}

% src: notes/Analysis/2026-08-16 Hard Sweep 2936132 (MiniMax, pinned Sonnet).md:125-147; notes/Analysis/hard-sweep-2936132-minimax-analyses.json (run 2936132-2510.08177-bf5a5f, round 56); notes/Analysis/hard-sweep-2936132-minimax-runs.json (model, batch_id)
The signature of \texttt{reimplement-without-validating} is a reference the
paper supplies that the run never checks against. On arXiv paper 2510.08177
the agent wrote its own version of the paper's baseline, scored it below the
value the paper reports for that same baseline, and then kept building on its
own version. The disagreement is visible in the
agent's own closing numbers, and the run never returned to it.

\begin{agentturn}{Round 56, agent.\ Paper 2510.08177, MiniMax-M2.7, sweep 2936132.}
Best All: 40.82\% (ep 20)\\
Target (paper ProCo+MORE): 65.9\%\\
Paper CE baseline: 61.4\%\\
Our CE-only baseline: 54.21\%\\
Gap vs target: -25.08\%
\end{agentturn}

The third and fourth lines are the paper's own baseline and the agent's
reimplementation of it. That gap persisted to the end of the run.

The signature of \texttt{scope-substitution} is a round in which the agent
names the pinned arm and then chooses a different one. On arXiv paper
2505.10039 the agent made that choice at round 6, before writing any code,
giving implementation cost as the reason. It never measured the pinned arm,
and the graded number came from the arm it chose instead.

\begin{agentturn}{Round 6, agent.\ Paper 2505.10039, DeepSeek-V4-Flash-0731, sweep 2918306.}
The EAP method shows the largest gap and is the cleanest to implement (single forward/backward pass, no iterative search).
\end{agentturn}

% src: notes/Analysis/hard-sweep-2918306-dsv4-analyses.json (run 2918306-2505.10039-47d383, round 6)
Neither arm had released code, so either arm required a port, and the agent
chose between them on implementation effort.

The signature of \texttt{environment-fights} is a version incompatibility in
the released stack that persists long enough to corrupt the run's own data. On
arXiv paper 2511.20906 an incompatible pair of robosuite and mujoco versions

had already trained on the corrupted output by the time it discovered the
break.

\begin{agentturn}{Round 233, agent.\ Paper 2511.20906, DeepSeek-V4-Flash-0731, sweep 2918306.}
This is the smoking gun: **the saved abs dataset is broken** -{}- the abs actions don\textquotesingle t reproduce the expert trajectory even from the correct initial state.
\end{agentturn}

The defect is in the released code as it runs on this host, and the run
