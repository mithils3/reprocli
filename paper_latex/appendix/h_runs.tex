\newcommand{\runfacts}[8]{\noindent{\footnotesize Run \texttt{#1} in the run
logs. #2, #3 tier, arXiv~#4. Audit #5, #6; mode #7; #8.}\par\medskip}

The counts of Section~\ref{subsec:mechanisms} say how often each failure mode
occurs and little about what the work of a reproduction looks like from inside
a run. This appendix annotates ten of the 372 graded runs at the round level.
In three the agent repairs a defect in the authors' release before the graded
command runs, in three it adapts the released stack to our host and checks the
substitute against the authors' own path, in one a faithful run falls short
and is reported as measured, and in three a run that reached the graded
command produces an invalid number at a round quoted below. We selected them by
reading the dissection records of Appendix~\ref{app:taxonomy} under five
lenses (defects in the release, host adaptation, provenance work,
substitutions, and near misses), which nominated 37 runs; we verified 16 of the
nominations against the event transcript at the cited rounds, one failed, and
we kept ten of the fifteen for coverage of agents, tiers, and outcomes. Four
of the ten are DeepSeek-V4 runs and five are at the Run tier, and we did not
balance further, since the recoveries concentrate in the strongest agent and
in the tier where released code exists to repair. Each vignette gives the
run's identifier in the run logs of footnote~\ref{fn:artifacts}, the pinned
audit score and verdict, its primary mode, and one to three verbatim excerpts
with their round numbers; the decisive round, the one in which the transcript
shows the run being fixed or lost, is set in a gold box. Round numbers are the
transcript's own, so a tool result is cited at the round in which it returned. Figure~\ref{fig:run-timelines} places the ten on a
common round axis, coloured by the kind of tool call the agent made in each
round, with the annotated episode and its decisive round marked.
