% src: README.md:38-56; prompts/prompt_reproduce.txt, prompts/prompt_audit.txt, rubric_audit.md; paper_latex/prompts/; src/reprocli_repro/inputs.py:42-49
The supplementary material is one repository holding the dataset pipeline, the reproduction agent of
Appendix~\ref{app:harness}, the auditor of Appendix~\ref{app:rubric}, the
serving layer both attach to, the batch scripts that produced every sweep, and
the per-run evidence bundles the grades were computed on. The prompt templates
and rubric rendered in Appendices~\ref{app:prompts}, \ref{app:rubric}, and
\ref{app:construction} are the files it ships, up to the disclosed
substitution of the benchmark's name. Listing~\ref{lst:running-commands}
gives the three commands that serve a model, run one paper, and grade one run.

\begin{codebox}[lst:running-commands]{bash}{Serving a model, running one paper, and grading a run (sanitized)}
# Serve the agent model and publish the address other nodes reach it at.
$ PYTHONPATH=src python3 -m reprocli_serve \
    --model <hf-id-or-path> \
    --served-model-name <model-id> \
    --port 8000 \
    --tensor-parallel-size <tp> \
    --endpoint-file <endpoint-file>
$ export REPROCLI_ENDPOINT_FILE=<endpoint-file>

# Run one paper of the frozen benchmark against it.
$ PYTHONPATH=src python3 -m reprocli_repro \
    --paper-id <arxiv-id> \
    --split eval \
    --run-id <run-id> \
    --runs-dir <runs-dir> \
    --vllm-server-url <endpoint-url> \
    --served-model-name <model-id>

# Grade the resulting bundle with the pinned grader.
$ PYTHONPATH=src python3 -m reprocli_claude \
    --batch slurm-<jobid> \
    --runs-dir <runs-dir> \
    --split eval \
    --model claude-sonnet-5 \
    --extracted-output <verdicts.jsonl>
\end{codebox}

A tier job dispatches papers sorted by compute ceiling ascending, so cheap
papers land results early. The job also grades inline while the sweep is still
running, over a vLLM endpoint with a cap of 40 tool rounds. A killed job
resumes with \texttt{RESUME=1}, which skips papers whose verdict is on disk,
regrades nothing, and retries a paper that died without a verdict. A paper
that produced no bundle is recorded as a harness casualty and is not counted
as a model failure.

Grading a batch takes each paper's newest attempt and drops runs still in
progress unless \texttt{--include-running} is passed, because a half-written
bundle grades the harness. A verdict is rechecked from the run bundle of
Appendix~\ref{app:report-format} and the verdict row, which carries the score, the rationale, and
any cheat flags. Every table in this paper regenerates from the frozen split
files and those run records, so a reader can check a verdict against the run
it graded without rerunning anything.
