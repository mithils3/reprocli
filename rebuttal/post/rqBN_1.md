**W1: Validation of the auditor.**

We compared the auditor (Claude Sonnet 5) with one human grader on 372 runs, and the grader did not see the auditor's score. On the reproduced verdict, the auditor's precision is 64/73 = 88% and its recall is 64/83 = 77% (F1 0.82). The auditor is the stricter of the two in every tier. It missed 7, 7 and 5 runs that the human called reproduced at Run, Retrain and Reimplement and added 3, 4 and 2 that the human did not, so it counts 73 reproduced runs against the human's 83. On the full 0 to 10 scale the two differ by at most one point on 324 of the 372 runs (quadratic weighted kappa 0.89), and they agree on 42 of the 57 runs that either placed at 0 for a high-severity anti-cheat flag (full matrix in Appendix D).

**W2: Agent-writable logs without an integrity check.**

The concern is sound. The harness writes commands.log and trajectory.jsonl into the folder the auditor reads, and the sandbox mounts that folder read-write, so we checked whether any agent used this. We compared both files with the harness's own transcript, kept on the host outside the sandbox, for all 372 graded runs. Of the 45,861 entries that agent commands produced, 45,673 match exactly. The other 188 differ only in bookkeeping: 100 calls the harness refused before they ran, 25 first attempts of retried calls, and 63 GPU-time values that differ by about one second or less (Appendix A). A search of every agent command for writes to the two files found one, on a run the auditor had already scored 1 of 10, so the agents left the logs alone in 371 of 372 runs. We have also closed the gap: the harness now mounts both files read-only inside the sandbox and its file tools refuse them, so appending to, overwriting, deleting or renaming either file from inside fails (Appendix A).
