The supplementary material is a single repository containing the dataset
pipeline, the reproduction agent of Appendix~\ref{app:harness}, the auditor of
Appendix~\ref{app:rubric}, the serving layer they share, the batch scripts that
produced every sweep, and the run bundles the grades were computed on. The
prompt templates and rubric reproduced in Appendix~\ref{app:prompt-listings}
are the files from that repository. We ran the sweeps under a development name. The released files
use the public name RECLAIM in its place, and the printed listings are
otherwise verbatim.
Figure~\ref{lst:running-commands} shows the three commands that serve a
model, run one paper, and grade one run.

\begin{codebox}[lst:running-commands]{bash}{Serving, running, and grading}
# Serve the agent model and publish the address other nodes reach it at.
$ PYTHONPATH=src python3 -m reclaim_serve \
    --model <hf-id-or-path> \
    --served-model-name <model-id> \
    --port 8000 \
    --tensor-parallel-size <tp> \
    --endpoint-file <endpoint-file>
$ export RECLAIM_ENDPOINT_FILE=<endpoint-file>

# Run one paper of the frozen benchmark against it.
$ PYTHONPATH=src python3 -m reclaim_repro \
    --paper-id <arxiv-id> \
    --split eval \
    --run-id <run-id> \
    --runs-dir <runs-dir> \
    --vllm-server-url <endpoint-url> \
    --served-model-name <model-id>

# Hosted model: same run command, its API as the server URL, key and window exported.
$ export RECLAIM_API_KEY=<api-key> RECLAIM_CONTEXT_LENGTH=<window>
$ PYTHONPATH=src python3 -m reclaim_repro ... \
    --vllm-server-url https://api.meta.ai/v1 --served-model-name <model-id>

# Grade the bundle with the pinned grader (hosted sweeps: --batch <model>-<timestamp>).
$ PYTHONPATH=src python3 -m reclaim_claude \
    --batch slurm-<jobid> \
    --runs-dir <runs-dir> \
    --split eval \
    --model claude-sonnet-5 \
    --extracted-output <verdicts.jsonl>
\end{codebox}

A tier job runs its papers in ascending order of compute ceiling, so the
cheapest papers produce results early. The job also grades each run while the
sweep is still in progress, over a vLLM endpoint with a cap of 40 tool rounds.
We resume a killed job with \texttt{RESUME=1}, which skips papers whose
verdict is already on disk, regrades nothing, and retries any paper whose run
ended without a verdict. We record a paper that produced no bundle as a
harness failure, and we do not count it as a model failure.

When grading a batch we take each paper's newest attempt and drop runs still in
progress unless \texttt{-{}-include-running} is passed, since a half-written
bundle measures the harness. A reader can recheck any verdict from the run
bundle of Appendix~\ref{app:report-format} together with its verdict row,
which records the score, the rationale, and any anti-cheat flags. We
regenerate every table in this paper from the frozen split files and those run
records, so a reader can check a verdict against the run it graded without
rerunning anything.
