\section{Audit Rubric}
\label{app:rubric}

\subsection{Grading procedure}

Each audit grades one agent's attempt at one paper's central claim. The
auditor receives the claim with its pinned match target, a manifest of the run
bundle, and the frozen rubric text (Figure~\ref{lst:rubric-text}), and
it explores the bundle with the tools of Table~\ref{tab:audit-tools}, whose path
arguments resolve against the run directory and reject absolute paths,
backslashes, and parent references, so a grade can only cite the bundle under
audit. It places the run in the highest quality band the cited evidence meets,
then applies an integrity adjustment that can only lower the score. The rubric
sets a low-score prior, so a run with no evidence scores low, and a printed number is not treated as verified. The
auditor returns no verdict string, since the verdict is derived from its row in
code (Appendix~\ref{app:rubric-finalizer}), and it returns a confidence and a
one-paragraph rationale which, below confidence 0.6 or after a judgment call,
must say what a human should examine and which file to open. Where
recomputation is inexpensive it recomputes metrics from the stored predictions
and outputs, and the 60\,s shell timeout rules out re-running training or
evaluation; the prompt template is Figure~\ref{lst:audit-prompt}.

The auditor works through six criteria, citing bundle evidence for each. C1
fixes the target from the pinned tuple with the bar kind's operator and
tolerance. C2 verifies that code ran which computed the metric on the pinned
dataset, split, checkpoint, and model size. C3 locates the measured value with
its file and line. C4 tests its provenance. C5 applies C1 to the measured and
reference pair. C6 checks that the experiment is the one the claim rests on.
Relational claims get the same checks on the baseline side. C1 and C2 can end
the grade, since a claim with no checkable target and a number with no
execution trace both score 0. Each C4
break is a typed flag with cited evidence and one of three severities, and any
high-severity flag caps the score at 0. Released weights, datasets, splits,
configs, and code are inputs, whereas the graded quantity must be computed in
this run from this run's model outputs, so a value read from a shipped results
file and disclosed caps the band at 4 without a flag, while the same value in
the target slot is fabricated provenance.

\subsection{Score scale and verdicts}

Table~\ref{tab:rubric} lists the quality bands and the verdict derived from
each score, where a score of 1 yields \texttt{unverifiable} when the auditor
also reports that execution was not verified. We froze the rubric text on
2026-07-16, three days after the dataset freeze, and every pinned-auditor grade
reported in this paper postdates that freeze. No band credits a claimed
artifact wall, an agent's report that a required artifact could not be
obtained, since curation removed those papers from the frozen split
(Appendix~\ref{app:construction}), so the auditor grades what the run achieved
and writes a curation escalation into \texttt{methodology\_notes} for human
review.
